# 智能车辆监控系统文档

## 项目概述

这是一个基于Qt和FluentUI框架开发的智能车辆监控系统，具有实时数据监控、网络拓扑可视化、攻击检测等功能。

## 核心功能

### 1. 科技感仪表盘 (TechDashboard)
- 多车辆实时监控
- 攻击参数配置
- 网络拓扑可视化
- 科技感UI设计

### 2. 车辆数据管理 (HomePage)
- 车辆网络拓扑展示
- 实时数据更新
- 车辆状态监控
- 数据预处理功能

### 3. 地图与视频监控 (LayoutRight)
- 地图集成显示
- 视频监控区域
- 车辆仪表盘
- 用户信息配置

## 技术架构

### 前端技术
- **Qt 6.9.2**: 跨平台应用框架
- **FluentUI**: 现代化UI组件库
- **QML**: 声明式UI设计语言
- **Qt Location**: 地图服务集成

### 后端技术
- **C++**: 核心业务逻辑
- **CMake**: 构建系统
- **网络通信**: TCP客户端实现

### 数据模型
- **VehicleDataModel**: 车辆数据结构
- **AttackDataModel**: 攻击参数管理
- **SharedNetworkConnection**: 网络数据共享

## 页面架构

```
main.qml
├── Windows.qml (主窗口容器)
├── Leftpage.qml (左侧导航面板)
├── LayoutRight.qml (右侧主显示区)
│   ├── HomePage.qml (数据管理)
│   ├── 地图区域
│   └── 视频监控
├── TechDashboard.qml (科技感仪表盘)
└── Playmusic.qml (底部控制栏)
```

## 开发说明

### 环境要求
- Qt 6.9.2 或更高版本
- CMake 3.16+
- C++17 编译器

### 构建步骤
```bash
mkdir build && cd build
cmake ..
make
```

### 国际化支持
- 支持中英文切换
- 使用tr()和qsTr()函数
- 自动更新翻译文件

## 特色功能

### 多模式显示
- **简洁模式**: 科技感仪表盘，专注攻击监控
- **常规模式**: 完整功能界面，数据管理+地图+视频

### 实时数据更新
- 网络数据自动刷新
- 车辆状态实时监控
- 拓扑关系动态展示

### 攻击检测系统
- 8种攻击模式支持
- 参数化配置管理
- 批量攻击执行
