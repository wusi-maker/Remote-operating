# 智能车辆监控系统文档

## 项目概述

这是一个基于Qt和FluentUI框架开发的智能车辆监控系统，具有实时数据监控、网络拓扑可视化、攻击检测等功能。

## 核心功能

### 1. 主页 (Homepage)
**实现文件**: `src/Src/commonUI/HomePage.qml` 和 `src/Src/leftPage/Leftpage.qml`

**主要功能**:
- **Leftpage.qml**: 车辆设备数据简略显示、车辆选择（点击车辆后跳转到详细数据页面）、车辆设备管理（待实现：设备查找、删除、添加功能）
- **HomePage.qml**: 用户管理、云服务器连接控制、详细数据查看、云服务器状态监控（待实现）、车辆队列拓扑模式显示、手动控制车辆队列拓扑模式、队列及每辆车的详细数据表格显示

**核心功能**:
- 车辆拓扑可视化：支持直线和贝塞尔曲线连接
- 实时数据更新：动态显示车辆状态
- 交互式拓扑控制：支持手动调整车辆连接关系

### 2. 智能车辆监控系统 (Intelligent Vehicle Monitoring System)
**实现文件**: `src/Src/rightPage/LayoutRight.qml` 和 `src/Src/leftPage/Leftpage.qml`

**主要功能**:
- **Leftpage.qml**: 与主页相同的功能（车辆数据简略显示、选择、管理）
- **LayoutRight.qml**: 视频显示、地图显示、车辆行驶轨迹显示、车辆数据仪表盘展示、原始数据显示

**子组件**:
- **CombinedDashboardLayout.qml**: 仪表盘设计，展示车辆关键数据
- **DataListView.qml**: 详细数据列表，显示车辆各项参数

**核心功能**:
- 多维度数据展示：视频、地图、仪表盘三位一体
- 实时轨迹跟踪：动态显示车辆行驶路径
- 数据可视化：图表化展示车辆性能指标

### 3. 科技感仪表盘 (Tech Dashboard)
**实现文件**: `src/Src/commonUI/TechDashboard.qml`

**主要功能**:
- 网络攻击控制中心：支持对车辆队列进行网络攻击
- 攻击模式：DDoS攻击、重放攻击、欺骗攻击、混合攻击模式
- 参数配置：攻击频率、时长等参数设置
- 目标选择：指定攻击车辆、链路、传感器

**攻击配置**:
- 多车攻击示例参考：`src/Src/commonUI/attackJSON.json`
- 支持精确到传感器的攻击定位
- 实时攻击状态监控

**核心功能**:
- 科技感UI设计：现代化界面风格
- 多模式攻击支持：8种攻击模式
- 参数化配置管理：灵活的攻击参数设置
- 批量攻击执行：支持多目标同时攻击






## 其他功能

### 多模式显示
- **简洁模式**: 科技感仪表盘，专注攻击监控
- **常规模式**: 完整功能界面，数据管理+地图+视频

### 实时数据更新
- 网络数据自动刷新
- 车辆状态实时监控
- 拓扑关系动态展示

### 攻击检测系统
- 8种攻击模式支持
- 参数化配置管理
- 批量攻击执行

## 页面架构

```
main.qml
├── Windows.qml (主窗口容器)
├── Leftpage.qml (左侧导航面板)
├── LayoutRight.qml (右侧主显示区)
│   ├── HomePage.qml (数据管理)
│   ├── 地图区域
│   └── 视频监控
├── TechDashboard.qml (科技感仪表盘)
└── Playmusic.qml (底部控制栏)
```
