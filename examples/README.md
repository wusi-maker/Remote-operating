# 核心页面展示示例

本目录包含三个核心页面的独立演示版本，方便在博客中展示各个页面的特色功能。

## 页面概览

### 1. TechDashboard - 科技感仪表盘
- **特色**: 现代化UI设计，科技感十足
- **功能**: 多车辆监控、攻击参数配置、拓扑可视化
- **技术**: QML Canvas绘图、动态数据绑定、流畅动画

### 2. HomePage - 车辆数据管理
- **特色**: 数据可视化展示
- **功能**: 网络拓扑、数据预处理、状态监控
- **技术**: JSON解析、Canvas绘图、数据模型管理

### 3. LayoutRight - 综合显示区域
- **特色**: 多组件集成展示
- **功能**: 地图显示、视频监控、仪表盘
- **技术**: Qt Location、布局管理、组件通信

## 使用说明

这些示例文件是独立的QML文件，可以在Qt Creator中直接运行查看效果。

### 运行方式
1. 打开Qt Creator
2. 导入对应的QML文件
3. 运行查看效果

### 注意事项
- 示例文件可能需要根据实际环境调整路径
- 部分功能需要相关依赖库支持
- 建议在完整项目环境中运行以获得最佳效果
